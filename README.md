# python Unit Convertor App

This is a mini project for GUI and Python practice 
The application consist of these unit types ( mass - length - temperature ) displayed as buttons
once writing in the text box, the converted value appears instantly in the other text box

Libraries used : 
  1. sys (for application handling)
  2. PyQt5 (for GUI)

how to make it work : 
libraries listed above must be installed to run the program
